HOW TO ADD IMAGES
Just drop PNG files into these folders (no code changes, refresh the page):

assets/heroes/   one file per hero, named exactly like the "image" column of roster.csv:
  dre.png (Vanish)      patolas.png (Glove)    piky.png (Driver)     portuga.png (Sailor)
  felix.png (Squeak)    jozze.png (Monkey)     didi.png (Greyson)    couti.png (Trick)
  sacuber.png (Tune)    zwist.png (Claws)      kanga.png (Income)    emi.png (Hail)
  realize.png (Oak)     caiks.png (Clark)      artur.png (Bullseye)  yolos.png (Cigar)
  joniclan.png  manucss.png  pombo.png  sonecas.png   (locked heroes, shown in the hero panel)
  Used for the board token (cropped to a circle) and the side panels. Square images work best.

assets/tokens/   card_shield.png  rat.png  ink_machine.png  two_d_ret.png  cat.png  snowman.png  smoke.png
  (rat, cat, ink machine and two-d-ret are drawn on the board; snowman and smoke currently use built-in symbols)

assets/tiles/    one file per tile code used by the maps, e.g. BS.png RS.png BN.png RN.png MM.png WW.png
                 BT.png RT.png BA.png RA.png CP.png MP.png  (also HG.png and HT.png if you use those tiles)
  Drawn inside the hexagon, so use a roughly square image. Teleport arrows are drawn on top of BT/RT.

Any file that is missing falls back to a coloured placeholder / initials, so you can add images one at a time.
